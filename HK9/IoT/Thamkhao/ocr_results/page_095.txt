Tương tự như file Module, file Configuration này cũng gồm
2 thành phần là: configuralion Và implementaion. Phần
configuration thông thường không cần thêm vào bất cứ nội dung
gì. Phần ởmplementation liên kết với các components khác và kết
nối với các interface sử dụng trong file Module thông qua ký
hiệu kết nối ->.
